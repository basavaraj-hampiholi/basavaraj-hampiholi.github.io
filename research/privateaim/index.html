Research overview

Applied a federated learning framework across distributed clinical datasets at multiple university hospitals and executed an end-to-end pancreatic cancer use case to assess feasibility and analytical performance.

Federated learningClinical AIData privacy

Objectives

  • Support privacy-preserving analysis across distributed clinical datasets.
  • Assess feasibility and analytical performance through a pancreatic cancer use case.

Methodology

Apply the PrivateAIM federated learning framework across clinical datasets distributed between university hospitals, and execute an end-to-end pancreatic cancer analysis use case.

Key contributions

  • Applied a federated learning framework to distributed clinical data.
  • Executed an end-to-end pancreatic cancer use case for feasibility and performance assessment.

Results

The pancreatic cancer use case was executed end to end. Detailed feasibility findings and analytical performance figures are not included in the current public project summary.
